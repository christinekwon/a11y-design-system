Demo Store Cart, 4 items

Accessible cart drawer

Serve this page over HTTP. Opened straight from disk over file://, Chrome blocks ES modules as a cross-origin request, so cart.js never runs and the cart link navigates for real.

From this folder: python3 -m http.server 8000, then visit http://localhost:8000/demo.html.

A static harness for reviewing the template in a browser. The cart lives in memory and fetch is stubbed, so this page stands in for the Section Rendering API: it returns the same re-rendered markup the Liquid snippet produces server-side. The stylesheet and the JavaScript are the real files, unmodified.

What to try

  1. Open the cart with Enter. Focus lands on the cart title, so a screen reader announces "Your cart, 4 items" rather than "Close, button".
  2. Tab around. Focus stays inside the dialog and the page behind it is inert — both from showModal(), with no JavaScript of our own.
  3. Change a quantity. Focus stays on the control you were using, even though the whole cart was replaced, and the new subtotal is announced.
  4. Remove the last item in the list. Focus moves to the previous item's link; remove every item and it moves to the cart title.
  5. Set Product C to 5. It is limited to 2, so the stubbed response is a 422: the message appears under the input, is tied to it with aria-describedby, the value reverts, and the error is announced.
  6. Press Esc, or click the backdrop. Focus returns to the header link.
